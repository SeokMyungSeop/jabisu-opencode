# 그려서 설명하기

Sketchy는 장면을 몇 줄로 적어 주면 손그림처럼 그리고, 읽는 사람이 단계를 하나씩 넘겨 볼 수 있게 해 주는 그림 도구다. 그림은 HTML 파일로 작업실의 「그림」 폴더에 저장된다.

## 준비

1. sketch 도구(Sketchy 서버의 도구)가 보이면 바로 그린다.
2. 보이지 않으면 `sketchy_turn_on` 도구를 부른다. 그림 도구가 아직 없으면 이 도구가 사용자에게 내려받아도 되는지(약 28MB, 처음 한 번) 묻고, 허락하면 내려받아 켠다. 이미 있으면 켜기만 한다.
3. 사용자가 내려받기를 거절하거나 도구가 실패하면, 도구가 알려 준 이유를 그대로 전하고 글로 설명한다. 다른 방법으로 내려받거나 설치하려고 하지 않는다.

## 그리는 법

- 장면 문법은 sketch 도구 설명에 있다. 그대로 따른다. ID는 영문·숫자로, 이름표(label)와 제목·단계 글은 한국어로 쓴다.
- 한 그림에는 한 가지 이야기만 담는다. 상자는 4~8개가 알맞다. 더 많으면 그림을 나눈다.
- 이름표는 짧게 쓴다(한 줄에 12자 안팎). 긴 설명은 단계(step) 글이나 본문에 쓴다.
- 순서나 흐름이 있으면 step을 3~5개 넣어 하나씩 짚는다. 단계마다 한 가지만 말한다.
- 꾸미는 낱말(`!accent`, `@아이콘`, `(note)` 같은 것)은 문법에 정해진 자리에 쓴다. 자리가 틀리면 글자로 그려진다.
- 고칠 때는 처음부터 다시 그리지 말고 edit_sketch 도구로 바뀐 줄만 보낸다.

## 그린 뒤

1. 도구 결과에 겹침·넘침 같은 경고가 있으면, 사용자에게 보여 주기 전에 이름표를 줄이거나 상자를 나눠 다시 그린다.
2. 도구가 알려 준 HTML 파일을 사용자에게 보여 준다. 브라우저 도구(browser)가 있으면 그 파일을 앱 안 브라우저로 열고, 없으면 파일 이름을 알려 주며 눌러서 열라고 한다.
3. 그림만 주지 않는다. 그림이 보여 주는 내용을 글로도 짧게 설명한다(단계가 있으면 단계 순서대로).
4. 「그림」 폴더의 파일은 사용자의 것이다. 지우거나 정리하지 않는다.
