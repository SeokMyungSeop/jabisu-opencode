# 행정 문서 양식

보고서·결과보고·계획(안)·메모보고·회의록·출장결과보고·보도자료를 관공서 양식의 한글 파일로 만든다. 내용은 문서 양식 JSON으로 쓰고, `scripts/make_admin_doc.py`가 제목 상자, □ ○ - 내어쓰기, 표, 보도자료 머리표를 갖춘 .hwpx로 조립한 뒤 구조를 검증하고 표기를 검사한다. `<기본 폴더>`는 이 스킬의 기본 폴더(Base directory)다. 공문(기안문)은 한글 문서 스킬(hwpx)의 공문 양식으로 만든다.

이 스킬만으로 충분하다. 한글 문서 스킬(hwpx)을 따로 부르지 않고, `scripts/`의 소스도 읽지 않는다. JSON 꼴은 [forms.md](forms.md)에 다 있고, 스크립트는 실행만 한다.

## 원칙

- 사실만 쓴다. 사용자의 말, 첨부 자료, 업무 파일(work_search), 녹음 받아쓰기에 있는 것만 적는다. 숫자·날짜·참석자·발언·인용(○○ 국장은 "…"라고 말했다)을 지어내지 않는다. 모르는 칸은 `(확인 필요)`로 두고 마지막에 목록으로 묻는다.
- 꼭 필요한 정보가 비면 만들기 전에 한 번에 묻는다. 양식마다 필요한 정보는 [forms.md](forms.md)에 있다.
- 보고서 계열은 개조식으로 쓴다: □ 큰 항목, ○ 내용, - 세부, · 더 세부, ※ 참고. 끝맺음은 명사형이나 "-함", "-임"이다. 보도자료는 "-했다", "-밝혔다" 꼴의 문장으로 쓴다.
- 날짜는 `2026. 10. 28.(수)`, 시간은 `14:00`, 금액은 `30,000원`처럼 쓴다. 자세한 표기는 [writing-rules.md](writing-rules.md)에 있다.
- 법령을 근거로 들 때는 이름을 「」로 묶고 조문까지 쓴다(「보조금 관리에 관한 법률」 제26조의2). law_text로 원문을 확인한 뒤 쓰고, 완성 전에 law_verify로 인용을 확인한다. 법령 찾기가 설정되지 않았으면 `(확인 필요)`를 붙인다.

## 순서

1. 자료를 모은다. 첨부 파일은 read로 읽고, 관련 파일은 work_search로 찾는다. 회의 녹음은 read로 받아쓰기를 얻는다.
2. [forms.md](forms.md)에서 양식을 고르고, 빠진 필수 정보를 묻는다.
3. 작업실에 문서 양식 JSON을 쓴다(UTF-8, 경로는 `/`). 꼴은 forms.md에 있다.
4. 실행한다.

   ```bash
   python "<기본 폴더>/scripts/make_admin_doc.py" "<문서>.json"
   ```

   스크립트가 Python이나 lxml이 없다고 하면 그때 [python-setup.md](python-setup.md)대로 묻고 허락받은 뒤 설치한다.
5. 출력의 「표기 검사」와 「(확인 필요)」를 본다. 고칠 곳은 JSON을 고쳐 다시 실행한다. 사용자의 표현을 바꾸는 것은 권하기만 한다.
6. 만든 파일 경로, 확인이 필요한 항목, 확인하지 못한 근거를 짧게 알린다.

이미 있는 문서의 표기만 검사할 때는 이렇게 한다(.hwpx, .txt, .json).

```bash
python "<기본 폴더>/scripts/check_style.py" "<파일>"
```
