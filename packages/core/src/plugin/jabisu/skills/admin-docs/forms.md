# 양식과 문서 양식 JSON

## 공통 꼴

```json
{
  "form": "결과보고",
  "title": "바이오 기업 현장 간담회 결과 보고",
  "date": "2026. 10. 28.(수)",
  "author": "바이오산업팀",
  "meta": {"일시": "2026. 10. 27.(화) 14:00~16:00", "장소": "○○바이오센터", "참석": "기업 대표 8명 등 11명"},
  "body": [
    "□ 추진 개요",
    "○ 목적: …",
    "- 세부 내용",
    "※ 참고 사항",
    {"table": [["구분", "내용", "건수"], ["인력", "…", "6"]], "widths": [1, 4, 1]},
    "□ 향후 계획"
  ],
  "attachments": ["참석자 명단 1부."],
  "output": "바이오 간담회 결과 보고.hwpx"
}
```

- `form`: 보고서, 결과보고, 계획, 메모보고, 회의록, 출장결과보고, 보도자료 가운데 하나.
- `date`를 빼면 오늘 날짜가 들어간다. `author`는 부서나 작성자.
- `meta`는 개요 표다(왼쪽 항목, 오른쪽 내용). 내용 안의 `\n`은 칸 안 줄바꿈이다.
- `body`의 각 줄은 머리 기호로 단계가 정해진다: `Ⅰ.` 장 제목, `□` 큰 항목, `○` 내용, `- ` 세부, `·` 더 세부, `※` 참고. 기호가 없으면 보통 문단(보도자료 본문)이다. 빈 문자열은 빈 줄이다.
- 표는 `{"table": [[머리칸…], [칸…], …], "widths": [비율…]}`. 첫 줄은 머리칸(굵게, 회색)이다.
- `attachments`는 붙임 목록이다. 여러 개면 번호가 붙는다.
- `output`을 빼면 JSON과 같은 폴더에 제목 이름으로 저장한다.

## 보고서 · 결과보고 · 계획

- 필수: 제목, 무엇을 왜 했는지(또는 할지), 결과나 계획의 핵심.
- 구성 예: □ 추진 개요(목적·근거·기간) → □ 추진 내용(또는 결과) → □ 문제점 및 개선 방안 → □ 향후 계획. 계획(안)은 □ 추진 배경 → □ 추진 계획(일정·예산 표) → □ 기대 효과.
- 첫 쪽에 결론이 보이게 쓰고, 한 항목은 두세 줄을 넘기지 않는다.

## 메모보고

- 필수: 제목, 보고할 핵심 한두 가지.
- 한 쪽 안. □ 두세 개와 그 아래 ○만 쓴다. 표·붙임은 꼭 필요할 때만.

## 회의록

- 필수: 회의 이름, 일시, 장소, 참석자, 안건. 녹음이 있으면 받아쓰기를 근거로 쓴다.
- `meta`: 일시, 장소, 참석자, 안건(여러 개면 `\n`으로).
- `body`: □ 주요 논의 내용(안건별 ○, 발언 요지는 - "기관: 요지") → □ 결정 사항 → □ 향후 조치(표: 조치 사항, 담당, 기한).
- 받아쓰기의 화자 번호는 추정이다. 누가 말했는지 확실하지 않으면 `(확인 필요)`를 붙이고 사용자에게 묻는다.

## 출장결과보고

- 필수: 출장 기간, 출장지, 출장자, 목적, 주요 내용.
- `meta`: 출장 기간, 출장지, 출장자, 목적.
- `body`: □ 주요 내용 → □ 결과 및 조치 계획. 붙임: 사진, 받은 자료.

## 보도자료

- 필수: 무엇을 언제 했는지(또는 할지), 핵심 숫자, 담당 부서·담당자·연락처, 보도 일시. 기관장 발언은 사용자가 준 말만 쓴다.
- `agency`: 기관 이름(맨 위 가운데). `meta`: 보도 일시, 담당 부서, 담당자, 연락처(두 쌍씩 한 줄).
- `lead`: 제목 아래 부제 두세 줄, 각각 `- `로 시작.
- `body`: 첫 문단에 누가·언제·무엇을·왜를 담고(리드), 다음 문단에 배경과 세부, 끝에 계획. 문단마다 기호 없이 쓴다. 사진이 있으면 마지막 줄에 `※ 사진 있음`.

```json
{
  "form": "보도자료",
  "agency": "○○도",
  "title": "○○도, 그린바이오 실증사업 공모 최종 선정",
  "meta": {"보도 일시": "2026. 10. 28.(수) 배포 즉시", "담당 부서": "바이오산업팀", "담당자": "팀장 ○○○", "연락처": "000-000-0000"},
  "lead": ["- 국비 30억 원 확보, 2029년까지 실증 기반 구축"],
  "body": ["○○도는 … 28일 밝혔다.", "이번 사업으로 …", "※ 사진 있음"]
}
```
