# 공문서 표기 요점

「행정업무의 운영 및 혁신에 관한 규정」과 행정업무운영 편람의 표기 가운데 자주 틀리는 것만 모았다. 공문(기안문)의 자세한 작성법은 한글 문서 스킬의 `references/gonmunseo-2025-writing-rules.md`를 본다.

| 항목 | 이렇게 | 이렇게 쓰지 않음 |
| --- | --- | --- |
| 날짜 | 2026. 10. 28.(수) | 2026.10.28, 2026-10-28, 2026. 01. 05. |
| 기간 | 2026. 10. 21.(수)~10. 22.(목) | 10/21~10/22 |
| 시간 | 09:00, 15:30 (24시각제) | 오전 9시, 오후 3시 30분 |
| 금액 | 30,000원, 30억 원 | 30000원 |
| 공문의 금액(변조 방지) | 금113,560원(금일십일만삼천오백육십원) | |
| 법령 이름 | 「보조금 관리에 관한 법률」 제26조의2 제1항 | 보조금법 26조의2 |
| 책·신문 이름 | 『행정업무운영 편람』 | |
| 나열 | 인력·장비·판로 | 인력, 장비, 판로 (짧은 나열일 때) |

## 항목 기호

- 보고서(개조식): □ → ○ → - → · 순서. ※는 참고.
- 공문(기안문): 1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮ 순서. 하위 항목은 두 타씩 들여 쓴다.

## 끝맺음

- 보고서: 명사형이나 "-함", "-임"으로 짧게 끝낸다. "-습니다"를 섞지 않는다.
- 보도자료: "-했다", "-밝혔다", "-계획이다" 꼴의 문장.
- 공문: 본문이 끝나면 한 칸 띄우고 "끝."을 쓴다. 붙임이 있으면 붙임 표시 다음에 쓴다: `붙임  1. 참석자 명단 1부.  끝.`

## 쉬운 말로 다듬기

| 쓰지 않음 | 다듬은 말 |
| --- | --- |
| 익일, 금일, 명일 | 다음 날, 오늘, 내일 |
| 상기, 하기 | 위, 아래 |
| 당해 | 해당, 그 |
| ~에 의거 | ~에 따라 |
| 구비서류 | 갖춤 서류 |
| 시건장치 | 잠금장치 |
| 적의 조치 | 알맞게 조치 |
| 만전을 기하다 | 빈틈없이 하다 |
| ~에 있어서 | ~에서 |

`scripts/check_style.py`는 위 표기 가운데 규칙으로 가릴 수 있는 것(날짜·시간·금액, 「」 없는 법령 이름, 다듬을 말)을 찾아 준다. 문맥이 필요한 것은 사람이 판단한다.
