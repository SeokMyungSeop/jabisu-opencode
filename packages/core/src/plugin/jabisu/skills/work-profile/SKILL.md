# 내 업무 프로필 만들기·고치기

`내 업무.md`는 사용자의 소속과 담당 업무를 적은 파일이다. 자비수는 모든 대화에서 이 파일을 지침으로 읽는다. 위치는 `__JABISU_WORK_PROFILE__`이다. 이 경로 그대로 읽고 쓰고, 다른 곳에 만들거나 셸로 경로를 알아보지 않는다. 사용자가 직접 고칠 수도 있다.

## 원칙

- 사무분장표(업무분장표)나 사용자가 말한 내용에 있는 업무만 적는다. 업무를 지어내거나 넓히지 않는다.
- 사무분장표와 사용자가 말한 내용만 쓴다. 빈 칸(기관·부서 이름 등)을 채우려고 다른 문서나 폴더를 열어 보지 않는다. 모르는 칸은 `(확인 필요)`로 두고 마지막에 묻는다.
- 업무 이름은 원문 표현을 그대로 쓴다. 하위 사업도 원문대로 적는다.
- 다른 사람은 이름 대신 자리로 적는다. 예: "팀장(행정5급)", "행정7급".
- 「관련 업무」(회색지대)는 사용자가 확인한 것만 적는다. 짐작으로 채우지 않는다.
- 이미 파일이 있으면, 바꾸기 전에 무엇이 달라지는지 보여 주고 허락을 받는다.

## 사무분장표로 만들기

1. 사무분장표 파일을 찾는다. 첨부되었거나 경로를 받았으면 그 파일을 쓰고, 없으면 work_search 도구로 "사무분장" 또는 "업무분장"을 찾아 후보를 보여 준다. 그래도 없으면 폴더를 뒤지지 말고, 파일을 첨부하거나 **설정 → 환경 설정 → 업무 비서**에서 자비수 업무 폴더(사무분장표를 둔 폴더)를 추가해 달라고 한다.
2. read 도구로 읽는다. 한글 표는 합쳐진 칸까지 읽힌다.
3. 표에 있는 자리를 팀·직급·전화번호로 짧게 보여 주고, 사용자의 자리가 어느 것인지 묻는다. 사용자가 이미 자리를 말했으면 묻지 않는다.
4. 고른 자리의 「담당업무」를 주업무로, 「업무대행」 칸을 대행으로 옮긴다.
   - 내가 대신하는 업무: 다른 자리의 대행 칸에 사용자의 자리가 적혀 있으면, 그 자리의 업무를 적는다.
   - 나를 대신하는 사람: 사용자 자리의 대행 칸에 적힌 자리를 적는다.
5. 아래 양식대로 쓴다. 기준일은 사무분장표에 적힌 날짜, 없으면 오늘 날짜를 쓴다.
6. 파일을 저장하고, 무엇을 적었는지 짧게 알린다.

## 바뀐 업무 반영하기

- 새 사무분장표가 오면, 이전 파일과 비교해 빠진 업무는 「지난 업무」로 옮기고 끝난 날짜를 적는다. 새 업무에는 시작 날짜를 적는다.
- 사용자가 말로 바꾸라고 하면 그 부분만 고치고 날짜를 적는다.
- 「업무 메모」는 사용자가 쌓아 온 노하우이므로 지우지 않는다.

## 양식

```markdown
# 내 업무

- 소속: <기관> <부서> <팀>
- 직급: <직급>
- 기준: <YYYY-MM-DD> 사무분장

## 주업무
- <업무> (<YYYY-MM-DD>~)
  - <하위 사업>

## 대행
- 내가 대신하는 업무: <자리> — <업무 요약>
- 나를 대신하는 사람: <자리>

## 관련 업무 (확인한 회색지대)
- (아직 없음)

## 지난 업무
- (아직 없음)

## 업무 메모
- (노하우, 자주 쓰는 서식, 연락처 위치 등)
```
